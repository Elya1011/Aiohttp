# Привет!


Данная работа является учебным заданием по созданию API, написанном на aiohttp.
Прежде, чем начать следует создать свой .env файл с таким содержимым:  

SECRET_KEY=*ваш ключ*  
USER_DB=*ваш юзер*  
PASSWORD_DB=*ваш пароль*  
NAME_DB=*имя вашей db*

secret_key генерируется в файле generate_key.py, поэтому запускаем сначала этот файл,
в результате получаем наш ключ и в этот же файл дописываем остальные необходимые переменные

Запускать проект нужно из файла **main.py**
